# YEAKUB FF TOURNAMENT

A responsive starter website for a community tournament project.

## Included
- Responsive tournament home page
- Exactly two tournaments marked FREE
- Tournament selection and registration preview form
- Results section

## Important limitations
This is a front-end demo only. It does not save player registrations, provide real login, manage an admin panel, distribute room credentials, process payments, or publish results from a database. Do not collect real player data or money until a secure backend and appropriate policy/legal checks are in place.

## Run locally
Open `index.html` in a browser, or serve this folder with a static web server.

## GitHub Pages
After uploading the files to a GitHub repository:
1. Open repository Settings.
2. Open Pages.
3. Choose deploy from branch `main`, folder `/ (root)`.
4. Save and wait for the published URL to appear.

Use only assets and game branding you have permission to use. Check applicable laws, game publisher rules, and platform policies before offering paid entry or cash prizes.
